
# Day 1 - AI Agents Workshop

## Project Title
AI Assistant for a Grocery Store

## Objective
To understand the fundamentals of Large Language Models (LLMs) and perform practical experiments using the Groq API.

## Tasks Completed
1. Temperature Experiment
2. Hallucination
3. No Memory
4. Token Comparison
5. Grocery Store AI Assistant

## Technologies Used
- Python
- Google Colab
- Groq API
- OpenAI Python Library

## Model
openai/gpt-oss-20b

## Learning Outcomes
- Understanding temperature and creativity.
- Identifying AI hallucinations.
- Understanding conversation memory.
- Comparing token usage in English and Telugu.
- Creating a business-specific AI assistant.
